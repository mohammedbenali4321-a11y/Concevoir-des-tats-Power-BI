##  Project Objective

This project is part of the official preparation path for the **PL-300** exam. The main objective is to design, structure, and optimize interactive analytical reports in **Microsoft Power BI Desktop** using the **Adventure Works** enterprise dataset (`DAte 8-Starter-Sales-Analysis`).

Through this hands-on lab, the following core skills are demonstrated:

* **Report Architecture Design:** Multi-page structuring (Sales Overview, Detailed Analysis, Intuitive Navigation).
* **Branding & Visual Identity:** Applying custom JSON themes (`CY24SU02.json`) and integrating corporate visual assets (Adventure Works Logo).
* **Data Visualization & Storytelling:** Selecting appropriate visuals (line charts, bar charts, KPI cards, slicers) to drive strategic decision-making.
* **Data Modeling & Performance:** Leveraging an optimized star schema data model for sales analysis.
